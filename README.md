# gis-data-scrape
public sourced data scraped geospatial info --> visual maps w/ dropdown info 

## Packages

- `az_heritage_spanish_trails/` - public Arizona Indigenous heritage sites,
  Spanish colonial public sites, Old Spanish National Historic Trail Arizona
  lines, and Juan Bautista de Anza National Historic Trail Arizona lines in
  GeoJSON and KMZ formats.
- `arizona_gold_gis_scripts/` - Arizona gold and claim-status screening scripts.
- `arizona_historic_airfields/` - historic Arizona airfield KMZ builders.
- `arizona_meteorite_radar_screening/` - Arizona archival radar scan tooling.
- `az_tunnel_map/` - Arizona tunnel portal map builder.
