# Arizona Historic Airfields

Build KMZ, KML, and GeoJSON packages for historic Arizona airfield research.

## Scripts

- `build_luke_aux_airfields_kmz.py` builds the historic Luke auxiliary airfields package.
- `build_phoenix_historic_airfields_kmz.py` builds the Greater Phoenix closed/abandoned historic airfields package and includes the historic NAF/NAS Litchfield Park aircraft boneyard placemark.

The outputs are screening-grade map layers intended for Google Earth and QGIS review.
